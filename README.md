🎹 mpphaunted
Онлайн-пианино для совместной игры в реальном времени. Клон multiplayerpiano.net, написанный за неделю.

Что это
Веб-приложение, где несколько человек могут одновременно играть на пианино и слышать друг друга. Ноты синхронизируются через WebSocket, так что задержка минимальная.

Возможности
Совместная игра на пианино в реальном времени

Бот, который умеет отвечать (или не умеет)

Работает в браузере, ничего ставить не надо

Docker-образ для быстрого развёртывания

Стек
Node.js — серверная часть

WebSocket — синхронизация в реальном времени

HTML/JavaScript — клиент

Docker — контейнеризация

GitHub Actions — CI/CD

Быстрый старт
bash
npm install
node server.js
Открой http://localhost:3000 в браузере — и играй.

Через Docker
bash
docker build -t mpphaunted .
docker run -p 3000:3000 mpphaunted
Демо
mpp.haunted.onrender.com

⚠️ На бесплатном тарифе Render сервис засыпает при неактивности. Первый запрос может занять до минуты — это нормально.
